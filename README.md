# Ready Instrument One

Turn any MIDI controller into an instrument that is always ready.

This public repository contains the product website and public release assets for
Ready Instrument One. The application source is maintained privately.

## Website

The product website now lives at
[modalsignal.com/ready-instrument-one](https://modalsignal.com/ready-instrument-one).
The HTML pages in [`site/`](site/) remain on GitHub Pages as redirects for old
links. The public beta manifest remains available from this repository.

The download panel reads this repository's GitHub Releases feed. Until a public
release with a Windows setup executable exists, it remains in a clearly marked
"preparing" state.

The site uses Cloudflare Web Analytics for privacy-first aggregate traffic and
performance measurement. Its public data practices are documented on the
website's privacy page. The application itself does not send analytics. Beta
feedback is collected voluntarily through an embedded, no-login Tally form.

## Releases

Public releases are promoted from a manually approved and tested candidate in
the private application repository. Installers are intentionally not built in
this repository.
