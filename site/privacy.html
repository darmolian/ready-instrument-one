Privacy

Useful information,
not user profiles.

Ready Instrument One is designed to be useful without requiring an account or quietly collecting information from the application.

The application

Ready Instrument One does not automatically send usage information, audio, MIDI data, diagnostics or crash reports. Diagnostic logs and crash dumps remain on your computer unless you choose to share them when asking for help.

By default, the application checks a small public version file at most once a day to see whether a newer beta is available. This request contains no installation identifier, usage information, device details, MIDI data, plug-in information or diagnostics. Automatic checks can be turned off in Application Settings, where you can still check manually. The version file is hosted by GitHub Pages and requests are processed under GitHub's privacy statement.

Website analytics

This website uses Cloudflare Web Analytics to understand aggregate website traffic and page performance. Cloudflare Web Analytics does not use cookies or create individual visitor profiles, and it is not used for advertising.

The information helps answer basic questions such as whether the site is being visited, how people arrive, and which pages are useful. Read more in Cloudflare’s Web Analytics documentation.

Downloads and external services

Application downloads and release notes are hosted by GitHub. GitHub provides aggregate download counts for release files and processes requests under its own privacy statement.

Links to GitHub and other external services take you to sites governed by their own privacy practices.

Feedback

Providing feedback is voluntary. The embedded feedback form is provided by Tally, which processes the form responses and the technical information needed to deliver its service. You choose what information to include, and no sign-in is required.

Ready Instrument One does not sell personal information or use feedback for advertising. Only provide contact information if you would like a reply. Learn more in Tally’s privacy and GDPR information.

Questions

For questions about this privacy statement, contact Darmolian through GitHub.
